## Codebase Patterns
- Use `npm run typecheck` to verify TypeScript compilation before commits
- JSON responses need explicit `Content-Type: application/json` header
- Router uses pattern `/path/:param` format, extracts params via regex
- HTTP status codes: 200 OK, 400 Bad Request, 401 Unauthorized, 404 Not Found, 405 Method Not Allowed
- Parse request body with `request.text()` then `JSON.parse()` for better error control
- Empty request bodies should be handled gracefully (treat as empty object)
- Webhook handlers implement WebhookHandler interface with verify() and normalize() methods
- Handler structure: src/handlers/<source>/{index.ts, verify.ts, normalize.ts}
- Web Crypto API available via global `crypto.subtle` for HMAC verification
- Must read request body as text before signature verification (can't reuse stream)
- Environment variables defined in Env interface in src/index.ts
